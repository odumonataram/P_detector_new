About Plagiarism Detection System

Overview

This plagiarism detection system is designed to help educators and students identify potential plagiarism in academic documents. Using advanced text analysis algorithms, the system compares submitted documents against a database of previously submitted work.

Features

📄 Multi-Format Support

Supports PDF and DOCX document formats

🔍 Advanced Detection

Uses TF-IDF vectorization and cosine similarity for accurate detection

📊 Comprehensive Reports

Detailed reports with highlighted sections, charts, and statistics

🎨 Color-Coded Highlights

Visual representation of similarity levels (Green: 0-20%, Yellow: 21-50%, Orange: 51-80%, Red: 81-100%)

📈 Analytics Dashboard

Admin dashboard with statistics and trends

🔒 Local Storage

All data stored locally without external database dependencies

How It Works

  1. Upload: Students or lecturers upload documents with student information
  2. Text Extraction: System extracts text from PDF or DOCX files
  3. Preprocessing: Text is cleaned, normalized, and tokenized
  4. Comparison: Document is compared against all stored submissions using TF-IDF and cosine similarity
  5. Analysis: Matching sections are identified and scored
  6. Report Generation: Comprehensive report is created with highlights, charts, and metadata

Technology Stack

  • Backend: Python, Flask
  • Text Processing: NLTK, scikit-learn
  • Document Handling: python-docx, pdfplumber
  • Visualization: Matplotlib, Seaborn
  • Storage: JSON-based local file system

Similarity Color Legend

0-20% (Green)

Low similarity - Acceptable

21-50% (Yellow)

Moderate similarity - Review recommended

51-80% (Orange)

High similarity - Investigation needed

81-100% (Red)

Very high similarity - Likely plagiarism

Important Notes

  • The system automatically excludes References and Bibliography sections from comparison
  • All uploaded documents are stored locally in the system for future comparisons
  • Similarity scores are based on algorithmic comparison and should be reviewed by instructors
  • The system does not check against external sources or the internet
  • Maximum file size: 16MB
